Transliterates selected text.<br />
To use, select a text segment, then right-click and click the transliterate text plugin.<br />
To enable after cloning, go to about:debugging -> This Firefox -> select one of the files in the cloned repository.<br />
Currently has a limitation where it doesn't work with Japanese Kanji characters due to not being a full translator and the multiple potential transliterations of Kanji characters.
